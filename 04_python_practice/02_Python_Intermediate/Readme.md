# ⚡ Python Intermediate

This folder contains Jupyter notebooks that build on **Python Basics** and prepare you for real-world data engineering tasks: clean control flow with exceptions, efficient iteration with iterators/generators, functional patterns (`lambda`, `map`, `filter`, `reduce`), and performance profiling/optimization.

> 💻 You’ll commit your progress and submit via **PR** using the Day-3 Git workflow.

---

## 🎯 What You’ll Learn

* **Error Handling & Robust Code** – `try/except/else/finally`, custom exceptions, and context managers  
* **Iterators & Generators** – memory-efficient pipelines and lazy evaluation  
* **Functional Patterns** – `lambda`, `map`, `filter`, `reduce`, and when to prefer comprehensions  
* **Performance Optimization** – measure first (time & memory), profile, and apply targeted improvements  

---

## 📝 Prerequisites

* Completion of **Python Basics** (numbers, strings, `if/else`, loops, lists/sets/dicts, functions)  
* A project environment created with **uv**, selected as your Jupyter kernel (see `02_Installation_and_setup/`)  

---

## 🏁 Getting Started

1. Open this folder in **VS Code** or **JupyterLab**  
2. Ensure your **virtual environment** is active and selected as the kernel  
3. Open a notebook and run cells with **Shift + Enter**  

> 💡 **Tip:** Commit early and often (e.g., per notebook section). Always **Restart Kernel → Run All** before committing.
